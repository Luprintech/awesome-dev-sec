## Cybersecurity

### Pentesting & Offensive

- [ffuf](https://github.com/ffuf/ffuf) - Fast web fuzzer written in Go.
- [Gobuster](https://github.com/OJ/gobuster) - Directory, DNS and vhost brute-forcing.
- [Hashcat](https://github.com/hashcat/hashcat) - World's fastest password recovery tool.
- [John the Ripper](https://github.com/openwall/john) - Password cracker.
- [Metasploit Framework](https://github.com/rapid7/metasploit-framework) - Penetration testing framework.
- [Nmap](https://github.com/nmap/nmap) - Network discovery and security scanning.
- [Nuclei](https://github.com/projectdiscovery/nuclei) - Template-based vulnerability scanner.
- [OWASP ZAP](https://github.com/zaproxy/zaproxy) - Web application security scanner and proxy.
- [sqlmap](https://github.com/sqlmapproject/sqlmap) - Automatic SQL injection and DB takeover tool.
- [WPScan](https://github.com/wpscanteam/wpscan) - WordPress vulnerability scanner.

### Recon & OSINT

- [Amass](https://github.com/owasp-amass/amass) - Attack surface mapping and asset discovery.
- [httpx](https://github.com/projectdiscovery/httpx) - Fast HTTP probing toolkit.
- [Recon-ng](https://github.com/lanmaster53/recon-ng) - Web reconnaissance framework.
- [Sherlock](https://github.com/sherlock-project/sherlock) - Hunt usernames across social networks.
- [SpiderFoot](https://github.com/smicallef/spiderfoot) - OSINT automation.
- [Subfinder](https://github.com/projectdiscovery/subfinder) - Passive subdomain discovery.
- [theHarvester](https://github.com/laramies/theHarvester) - Gather emails, subdomains and hosts.

### Defense & Monitoring

- [CrowdSec](https://github.com/crowdsecurity/crowdsec) - Collaborative, behavior-based IPS.
- [Falco](https://github.com/falcosecurity/falco) - Cloud-native runtime threat detection.
- [Gitleaks](https://github.com/gitleaks/gitleaks) - Detect secrets in git repos.
- [Semgrep](https://github.com/semgrep/semgrep) - Lightweight static analysis for many languages.
- [Sigma](https://github.com/SigmaHQ/sigma) - Generic signature format for SIEM detection rules.
- [Suricata](https://github.com/OISF/suricata) - Network IDS/IPS and security monitoring engine.
- [Trivy](https://github.com/aquasecurity/trivy) - Scanner for vulnerabilities, misconfigurations and secrets.
- [TruffleHog](https://github.com/trufflesecurity/trufflehog) - Find and verify leaked credentials.
- [Wazuh](https://github.com/wazuh/wazuh) - Open-source XDR and SIEM platform.
- [Zeek](https://github.com/zeek/zeek) - Network analysis framework.

### Reverse Engineering

- [Radare2](https://github.com/radareorg/radare2) - Reverse engineering framework.
- [x64dbg](https://github.com/x64dbg/x64dbg) - Open-source Windows debugger.

## Agent Skills & MCP

Reusable skills, agents and tool servers for AI coding agents (Claude Code, Cursor, Codex and others).

### Essential Web Toolkit

The minimum set of skills, plugins and MCP servers to build a professional web app with an AI coding agent, from idea to deploy.

#### Design

- [Anthropic Knowledge Work Plugins](https://github.com/anthropics/knowledge-work-plugins) - Includes the `design` plugin: critique, accessibility review, UX copy and handoff.
- [Claude Plugins (official)](https://github.com/anthropics/claude-plugins-official) - Anthropic-managed directory of plugins, including `frontend-design`.
- [Impeccable](https://github.com/pbakaus/impeccable) - Design vocabulary for your agent: steer, critique, polish and audit frontends.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Design intelligence that generates a full design system per product type.

#### SEO

- [Claude SEO](https://github.com/AgriciDaniel/claude-seo) - SEO skill with sub-skills and agents for technical SEO, E-E-A-T, schema and GEO.

#### Build

- [Cloudflare Skills](https://github.com/cloudflare/skills) - Skills for building and deploying on Cloudflare.
- [Supabase Agent Skills](https://github.com/supabase/agent-skills) - Skills for working with Supabase: Postgres, RLS and auth.
- [Ultrapowers](https://github.com/ennio-datatide/ultrapowers) - Marketplace with `ultrapowers-dev`: 54 best-practice skills for languages and frameworks.
- [Vercel Plugin](https://github.com/vercel/vercel-plugin) - Vercel ecosystem plugin with skills for deploys, env vars and frameworks.

#### Connectors (MCP)

- [GitHub MCP Server](https://github.com/github/github-mcp-server) - GitHub's official MCP server for repos, issues, PRs and CI.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - Browser control through accessibility snapshots.
- [Supabase MCP](https://github.com/supabase-community/supabase-mcp) - Connect Supabase projects to your AI assistant.

#### Verify

- [Axe MCP Server](https://github.com/dequelabs/axe-mcp-server-public) - Deque's MCP server for accessibility testing and remediation.
- [Claude Code Plugins (petrovicistefan)](https://github.com/petrovicistefan/claude-code-plugins) - Plugin bundle with `e2e-test-generator`, `ci-optimizer` and `i18n-sync`.

#### Data

- [Scrapling](https://github.com/D4Vinci/Scrapling) - Web scraping framework with fetchers, spiders, CLI and MCP server.
