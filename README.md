## Web Development

### Frameworks & Libraries

- [Angular](https://github.com/angular/angular) - Full-featured TypeScript framework by Google.
- [Astro](https://github.com/withastro/astro) - Content-focused framework with minimal client-side JS.
- [Next.js](https://github.com/vercel/next.js) - The React framework for production.
- [React](https://github.com/facebook/react) - Library for building user interfaces.
- [shadcn/ui](https://github.com/shadcn-ui/ui) - Accessible, copy-and-paste components.
- [Svelte](https://github.com/sveltejs/svelte) - Compiler-based UI framework.
- [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss) - Utility-first CSS framework.
- [Vue](https://github.com/vuejs/core) - Progressive JavaScript framework.

### Backend

- [Django](https://github.com/django/django) - Batteries-included Python web framework.
- [Drizzle ORM](https://github.com/drizzle-team/drizzle-orm) - Lightweight, type-safe TypeScript ORM.
- [Express](https://github.com/expressjs/express) - Minimal Node.js web framework.
- [FastAPI](https://github.com/fastapi/fastapi) - Modern, fast Python API framework.
- [Hono](https://github.com/honojs/hono) - Small, fast web framework for any JS runtime.
- [Laravel](https://github.com/laravel/laravel) - Elegant PHP framework.
- [NestJS](https://github.com/nestjs/nest) - Progressive, structured Node.js framework.
- [Prisma](https://github.com/prisma/prisma) - Next-generation TypeScript ORM.
- [Supabase](https://github.com/supabase/supabase) - Open-source Firebase alternative built on Postgres.

### Tooling & Testing

- [Biome](https://github.com/biomejs/biome) - Fast formatter and linter for web projects.
- [Cypress](https://github.com/cypress-io/cypress) - End-to-end testing for the browser.
- [Lighthouse](https://github.com/GoogleChrome/lighthouse) - Audits for performance, accessibility and SEO.
- [Playwright](https://github.com/microsoft/playwright) - Cross-browser automation and testing.
- [Vite](https://github.com/vitejs/vite) - Next-generation frontend build tool.
- [Vitest](https://github.com/vitest-dev/vitest) - Vite-native unit testing framework.

## Cybersecurity

### Pentesting & Offensive

- [ffuf](https://github.com/ffuf/ffuf) - Fast web fuzzer written in Go.
- [Gobuster](https://github.com/OJ/gobuster) - Directory, DNS and vhost brute-forcing.
- [Hashcat](https://github.com/hashcat/hashcat) - World's fastest password recovery tool.
- [John the Ripper](https://github.com/openwall/john) - Password cracker.
- [Metasploit Framework](https://github.com/rapid7/metasploit-framework) - Penetration testing framework.
- [Nmap](https://github.com/nmap/nmap) - Network discovery and security scanning.
- [Nuclei](https://github.com/projectdiscovery/nuclei) - Template-based vulnerability scanner.
- [OWASP ZAP](https://github.com/zaproxy/zaproxy) - Web application security scanner and proxy.
- [sqlmap](https://github.com/sqlmapproject/sqlmap) - Automatic SQL injection and DB takeover tool.
- [WPScan](https://github.com/wpscanteam/wpscan) - WordPress vulnerability scanner.

### Recon & OSINT

- [Amass](https://github.com/owasp-amass/amass) - Attack surface mapping and asset discovery.
- [httpx](https://github.com/projectdiscovery/httpx) - Fast HTTP probing toolkit.
- [Recon-ng](https://github.com/lanmaster53/recon-ng) - Web reconnaissance framework.
- [Sherlock](https://github.com/sherlock-project/sherlock) - Hunt usernames across social networks.
- [SpiderFoot](https://github.com/smicallef/spiderfoot) - OSINT automation.
- [Subfinder](https://github.com/projectdiscovery/subfinder) - Passive subdomain discovery.
- [theHarvester](https://github.com/laramies/theHarvester) - Gather emails, subdomains and hosts.

### Defense & Monitoring

- [CrowdSec](https://github.com/crowdsecurity/crowdsec) - Collaborative, behavior-based IPS.
- [Falco](https://github.com/falcosecurity/falco) - Cloud-native runtime threat detection.
- [Gitleaks](https://github.com/gitleaks/gitleaks) - Detect secrets in git repos.
- [Semgrep](https://github.com/semgrep/semgrep) - Lightweight static analysis for many languages.
- [Sigma](https://github.com/SigmaHQ/sigma) - Generic signature format for SIEM detection rules.
- [Suricata](https://github.com/OISF/suricata) - Network IDS/IPS and security monitoring engine.
- [Trivy](https://github.com/aquasecurity/trivy) - Scanner for vulnerabilities, misconfigurations and secrets.
- [TruffleHog](https://github.com/trufflesecurity/trufflehog) - Find and verify leaked credentials.
- [Wazuh](https://github.com/wazuh/wazuh) - Open-source XDR and SIEM platform.
- [Zeek](https://github.com/zeek/zeek) - Network analysis framework.

### Reverse Engineering

- [Ghidra](https://github.com/NationalSecurityAgency/ghidra) - Software reverse engineering suite by the NSA.
- [Radare2](https://github.com/radareorg/radare2) - Reverse engineering framework.
- [x64dbg](https://github.com/x64dbg/x64dbg) - Open-source Windows debugger.

### Practice Labs

- [DVWA](https://github.com/digininja/DVWA) - Damn Vulnerable Web Application.
- [Juice Shop](https://github.com/juice-shop/juice-shop) - Intentionally insecure modern web app.
- [WebGoat](https://github.com/WebGoat/WebGoat) - Deliberately insecure app to learn web security.

### Knowledge Bases

- [Awesome Pentest](https://github.com/enaqx/awesome-pentest) - Curated pentesting resources.
- [Awesome Security](https://github.com/sbilly/awesome-security) - Curated security resources.
- [HackTricks](https://github.com/carlospolop/hacktricks) - Hacking techniques and tricks.
- [OWASP Cheat Sheet Series](https://github.com/OWASP/CheatSheetSeries) - Concise application security guidance.
- [OWASP Top 10](https://github.com/OWASP/Top10) - Most critical web application security risks.
- [OWASP WSTG](https://github.com/OWASP/wstg) - Web Security Testing Guide.
- [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) - Payloads and bypasses for web security.
- [SecLists](https://github.com/danielmiessler/SecLists) - Wordlists for security assessments.
