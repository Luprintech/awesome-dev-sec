# Contributing / Contribuir

Thanks for helping! / ¡Gracias por ayudar!

## Guidelines (EN)

1. **One repo per pull request.**
2. Add it to the most fitting section, in **alphabetical order**, in **both** `README.md` and `README.es.md`.
3. Use this format: `- [Name](https://github.com/owner/repo) - Short description ending with a period.`
4. The repo must be **actively maintained**, have a clear README, and be genuinely useful (no empty or spam repos).
5. Security tools must be for **legitimate, authorized use** (pentesting, defense, education).
6. No duplicates; search the list before adding.
7. Keep descriptions short and neutral (no marketing language).

## Guía (ES)

1. **Un repo por pull request.**
2. Añádelo en la sección que mejor encaje, en **orden alfabético**, tanto en `README.md` como en `README.es.md`.
3. Usa este formato: `- [Nombre](https://github.com/owner/repo) - Descripción corta terminada en punto.`
4. El repo debe estar **activamente mantenido**, tener un README claro y ser realmente útil (nada de repos vacíos o spam).
5. Las herramientas de seguridad deben ser para **uso legítimo y autorizado** (pentesting, defensa, educación).
6. Sin duplicados; busca en la lista antes de añadir.
7. Descripciones cortas y neutrales (sin lenguaje de marketing).
